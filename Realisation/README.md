# Realisation Portfolio Project

This is a personal portfolio project built with Laravel, designed to showcase a developer's projects, skills, and contact information. It follows an MVC (Model-View-Controller) architectural pattern with a strong emphasis on service-oriented design for business logic.

## Features

- **Developer Profile:** Displays personal information, title, bio, and contact details.
- **Project Listings:** Showcases a list of projects with titles, descriptions, images, and links to GitHub and live demos.
- **Project Details:** Provides a dedicated page for each project, including detailed information and associated technologies.
- **Technology Management:** Manages a list of technologies used across projects.
- **Responsive Design:** Built with Tailwind CSS for a modern and responsive user interface.

## Technologies Used

- **Laravel:** PHP Framework for the backend.
- **PHP:** Programming language.
- **Blade:** Laravel's templating engine for views.
- **Tailwind CSS:** Utility-first CSS framework for styling.

## Usage

- Navigate to the home page to see the developer's profile and a list of featured projects.
- Explore the "About" page for more details about the developer.
- Visit the "Projects" page to view all projects.
- Click on individual projects to see their detailed descriptions and technologies.
