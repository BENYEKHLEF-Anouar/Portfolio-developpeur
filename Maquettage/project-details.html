SoliRestaurant - Management App

A comprehensive restaurant management solution with a responsive customer interface and a powerful admin backend.

Project Overview

SoliRestaurant is a full-stack web application built to streamline restaurant operations. It features a responsive front-end with an integrated ordering system and a complete back-end to manage dishes, track orders, and view sales statistics.
